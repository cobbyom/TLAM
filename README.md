Project Test Images

This repository contains test image outputs from my project, which focuses on image classification and feature visualization using deep learning models.

Contents

The repository includes:
	•	Original Images – Raw input images used for testing.
	•	Layer Activation Maps – Visualizations of intermediate feature maps from the model’s layers.
	•	Overlays – Combined views of activation maps over the original images, highlighting regions of interest.
	•	Prediction Scores – Model output probabilities or class scores for each test image.

Purpose

These files are provided to:
	•	Document the model’s behavior and performance.
	•	Help analyze what the model is “looking at” when making predictions.
	•	Support debugging and improving feature learning in the model.

Usage

You can browse the files directly or use them in reports, presentations, or further analysis.
